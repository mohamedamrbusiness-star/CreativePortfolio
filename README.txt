DEPLOY ON GITHUB PAGES
1. Create a repo. Upload ALL files so index.html sits in the repo ROOT (not inside a folder):
   index.html admin.html content.js common.js style.css photo.jpg cv.pdf .nojekyll
2. Settings > Pages > Deploy from a branch > main / (root) > Save. Wait ~1 minute.
3. Site: https://USERNAME.github.io/REPO/   Admin: https://USERNAME.github.io/REPO/admin.html
4. In Admin > Publish: enter owner, repo, branch, and a fine-grained token (Contents: Read and write).
